grommunio Web can be operated almost entirely from the keyboard. The shortcuts come in two levels:

- **Basic** shortcuts are on by default. They are safe for everybody and don't interfere with the shortcuts of your browser.
- **Extended** shortcuts add many more, for example to reply or to create items. Switch them on under **Settings › Keyboard Shortcuts** › **Extended shortcuts on**, then reload grommunio Web.

![The Keyboard Shortcuts settings with the shortcut level and the list of shortcuts grouped by area](/img/web/web_settings_shortcuts.png)

On a Mac, use <kbd>Cmd</kbd> instead of <kbd>Ctrl</kbd> and <kbd>Option</kbd> instead of <kbd>Alt</kbd> (except in Safari, where <kbd>Ctrl</kbd> is kept). Tooltips of buttons show their shortcut when it is active.

## Basic shortcuts

| Keys | Action |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | Open the [command palette](/web/intro/#command-palette) |
| <kbd>Ctrl</kbd>+<kbd>F</kbd> | Jump to the search box; press again for the browser's own search |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Ctrl</kbd>+<kbd>Y</kbd> | Undo / redo the last action (when [undo](/web/intro/#undo-and-redo) is switched on) |
| <kbd>F5</kbd> | Refresh |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | Select all items |
| <kbd>Enter</kbd> | Open the selected item |
| <kbd>Delete</kbd> | Delete the selected item |
| <kbd>Shift</kbd>+<kbd>Delete</kbd> | Delete without moving to *Deleted Items* (can still be restored) |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | Print the selected or open item |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Save the open item |
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> | Send the open mail, meeting request or task request |
| <kbd>F2</kbd> | Rename the selected folder |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>Ctrl</kbd>+<kbd>V</kbd> | Copy / paste an appointment in the calendar |
| Context-menu key or <kbd>Shift</kbd>+<kbd>F10</kbd> | Open the context menu of the selected item |

## Extended shortcuts

### Navigation

| Keys | Action |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>0</kbd>…<kbd>9</kbd> | Switch to an application (Mail, Calendar, …) |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>1</kbd>…<kbd>9</kbd> | Switch between the views of an application |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>W</kbd> | Close the current tab |
| <kbd>Shift</kbd>+<kbd>Home</kbd> / <kbd>Shift</kbd>+<kbd>End</kbd> | Extend the selection to the first / last item |
| <kbd>Alt</kbd>+<kbd>S</kbd> | Open a shared folder or mailbox |

### Creating items

| Keys | Action |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>N</kbd> | New item of the current type |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>X</kbd> | New mail |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>A</kbd> | New appointment |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>V</kbd> | New meeting request |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>C</kbd> | New contact |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>D</kbd> | New distribution list |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>K</kbd> | New task |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>S</kbd> | New note |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>F</kbd> | New folder |

### Items and mail

| Keys | Action |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>R</kbd> | Reply |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>R</kbd> | Reply all |
| <kbd>Ctrl</kbd>+<kbd>F</kbd> (in the mail list or reading pane) | Forward |
| <kbd>Ctrl</kbd>+<kbd>E</kbd> | Edit as new |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>U</kbd> | Mark as read / unread |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>G</kbd> | Set or complete the follow-up flag |
| <kbd>Ctrl</kbd>+<kbd>G</kbd> | Assign categories |
| <kbd>Ctrl</kbd>+<kbd>M</kbd> | Copy or move the selected items |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>P</kbd> | Print the list |

### Calendar

| Keys | Action |
|---|---|
| <kbd>Alt</kbd>+<kbd>←</kbd> / <kbd>Alt</kbd>+<kbd>→</kbd> | Previous / next day, week or month |

:::tip
You can move through lists with the arrow keys and open submenus with <kbd>→</kbd>. A visible focus ring shows where you are when you use the keyboard.
:::
