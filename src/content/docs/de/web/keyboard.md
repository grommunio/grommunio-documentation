grommunio Web lässt sich fast vollständig mit der Tastatur bedienen. Die Tastenkombinationen gibt es in zwei Stufen:

- **Basis**-Tastenkombinationen sind standardmäßig aktiv. Sie sind für alle unbedenklich und stören die Tastenkombinationen Ihres Browsers nicht.
- **Erweiterte** Tastenkombinationen fügen viele weitere hinzu, etwa zum Antworten oder zum Anlegen von Elementen. Schalten Sie sie unter **Einstellungen › Tastenkombinationen** › **Erweiterte Shortcuts auf** ein und laden Sie grommunio Web neu.

![Die Einstellungen Tastenkombinationen mit der Stufe und der nach Bereichen gruppierten Liste](/img/web/de/web_settings_shortcuts.png)

Auf dem Mac verwenden Sie <kbd>Cmd</kbd> statt <kbd>Strg</kbd> und <kbd>Option</kbd> statt <kbd>Alt</kbd> (außer in Safari, wo <kbd>Ctrl</kbd> bleibt). In der Oberfläche heißen die Tasten wie auf englischen Tastaturen *CTRL*, *ALT* und *SHIFT*. Tooltips von Schaltflächen zeigen ihre Tastenkombination, wenn sie aktiv ist.

## Basis-Tastenkombinationen

| Tasten | Aktion |
|---|---|
| <kbd>Strg</kbd>+<kbd>K</kbd> | [Befehlspalette](/de/web/intro/#befehlspalette) öffnen |
| <kbd>Strg</kbd>+<kbd>F</kbd> | ins Suchfeld springen; erneut drücken für die Suche des Browsers |
| <kbd>Strg</kbd>+<kbd>Z</kbd> / <kbd>Strg</kbd>+<kbd>Y</kbd> | letzte Aktion rückgängig machen / wiederholen (wenn [Rückgängig](/de/web/intro/#rückgängig-und-wiederholen) eingeschaltet ist) |
| <kbd>F5</kbd> | neu laden |
| <kbd>Strg</kbd>+<kbd>A</kbd> | alle Elemente auswählen |
| <kbd>Enter</kbd> | ausgewähltes Element öffnen |
| <kbd>Entf</kbd> | ausgewähltes Element löschen |
| <kbd>Umschalt</kbd>+<kbd>Entf</kbd> | löschen, ohne nach *Gelöschte Elemente* zu verschieben (lässt sich noch wiederherstellen) |
| <kbd>Strg</kbd>+<kbd>P</kbd> | ausgewähltes oder geöffnetes Element drucken |
| <kbd>Strg</kbd>+<kbd>S</kbd> | geöffnetes Element speichern |
| <kbd>Strg</kbd>+<kbd>Enter</kbd> | geöffnete E-Mail, Besprechungsanfrage oder Aufgabendelegation senden |
| <kbd>F2</kbd> | ausgewählten Ordner umbenennen |
| <kbd>Strg</kbd>+<kbd>C</kbd> / <kbd>Strg</kbd>+<kbd>V</kbd> | Termin im Kalender kopieren / einfügen |
| Kontextmenütaste oder <kbd>Umschalt</kbd>+<kbd>F10</kbd> | Kontextmenü des ausgewählten Elements öffnen |

## Erweiterte Tastenkombinationen

### Navigation

| Tasten | Aktion |
|---|---|
| <kbd>Strg</kbd>+<kbd>0</kbd>…<kbd>9</kbd> | zu einer Anwendung wechseln (Mail, Kalender, …) |
| <kbd>Strg</kbd>+<kbd>Alt</kbd>+<kbd>1</kbd>…<kbd>9</kbd> | zwischen den Ansichten einer Anwendung wechseln |
| <kbd>Strg</kbd>+<kbd>Alt</kbd>+<kbd>W</kbd> | aktuelle Registerkarte schließen |
| <kbd>Umschalt</kbd>+<kbd>Pos1</kbd> / <kbd>Umschalt</kbd>+<kbd>Ende</kbd> | Auswahl bis zum ersten / letzten Element erweitern |
| <kbd>Alt</kbd>+<kbd>S</kbd> | gemeinsamen Ordner oder gemeinsames Postfach öffnen |

### Neue Elemente

| Tasten | Aktion |
|---|---|
| <kbd>Strg</kbd>+<kbd>Alt</kbd>+<kbd>N</kbd> | neues Element des aktuellen Typs |
| <kbd>Strg</kbd>+<kbd>Alt</kbd>+<kbd>X</kbd> | neue E-Mail |
| <kbd>Strg</kbd>+<kbd>Alt</kbd>+<kbd>A</kbd> | neuer Termin |
| <kbd>Strg</kbd>+<kbd>Alt</kbd>+<kbd>V</kbd> | neue Besprechungsanfrage |
| <kbd>Strg</kbd>+<kbd>Alt</kbd>+<kbd>C</kbd> | neuer Kontakt |
| <kbd>Strg</kbd>+<kbd>Alt</kbd>+<kbd>D</kbd> | neue Verteilerliste |
| <kbd>Strg</kbd>+<kbd>Alt</kbd>+<kbd>K</kbd> | neue Aufgabe |
| <kbd>Strg</kbd>+<kbd>Alt</kbd>+<kbd>S</kbd> | neue Notiz |
| <kbd>Strg</kbd>+<kbd>Alt</kbd>+<kbd>F</kbd> | neuer Ordner |

### Elemente und E-Mail

| Tasten | Aktion |
|---|---|
| <kbd>Strg</kbd>+<kbd>R</kbd> | antworten |
| <kbd>Strg</kbd>+<kbd>Alt</kbd>+<kbd>R</kbd> | allen antworten |
| <kbd>Strg</kbd>+<kbd>F</kbd> (in der E-Mail-Liste oder im Lesebereich) | weiterleiten |
| <kbd>Strg</kbd>+<kbd>E</kbd> | als neu bearbeiten |
| <kbd>Strg</kbd>+<kbd>Alt</kbd>+<kbd>U</kbd> | als gelesen / ungelesen markieren |
| <kbd>Strg</kbd>+<kbd>Alt</kbd>+<kbd>G</kbd> | Kennzeichnung setzen oder erledigen |
| <kbd>Strg</kbd>+<kbd>G</kbd> | Kategorien zuweisen |
| <kbd>Strg</kbd>+<kbd>M</kbd> | ausgewählte Elemente kopieren oder verschieben |
| <kbd>Strg</kbd>+<kbd>Alt</kbd>+<kbd>P</kbd> | Liste drucken |

### Kalender

| Tasten | Aktion |
|---|---|
| <kbd>Alt</kbd>+<kbd>←</kbd> / <kbd>Alt</kbd>+<kbd>→</kbd> | vorheriger / nächster Tag, Woche oder Monat |

:::tip
In Listen bewegen Sie sich mit den Pfeiltasten, Untermenüs öffnen Sie mit <kbd>→</kbd>. Ein sichtbarer Fokusrahmen zeigt, wo Sie sich befinden, wenn Sie die Tastatur verwenden.
:::
